# @open-work-org/meta-mcp-server

Self-hosted Meta MCP connector for Facebook Pages, Instagram, Threads, Ads Manager, Commerce, Conversions API, audiences, insights, and chart generation.

## Install

```bash
npm install -g @open-work-org/meta-mcp-server
```

The package provides the `meta-mcp-server` executable. Configure `META_ACCESS_TOKEN` and, when using Threads tools, `THREADS_ACCESS_TOKEN` in the MCP client's server environment.
